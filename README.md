# 体育ツールBOX

体育の授業中によく使う道具を、タブレット1台ですぐに使えるようにした先生向けWebツールです。

## Ver.1

- ゲームボード：得点板＋タイマー（通常／試合／インターバル）
- 対戦メーカー：2〜10チーム、総当たり／各チーム試合数／ランダム対戦、1〜3コート、審判割り当て
- 作戦ボード：7競技のコート、選手・ボール移動、矢印・線、作戦3枠保存
- 記録・ストップウォッチ：個人ラップ、複数ゴール記録
- ふりかえり記入：授業後の記録、一覧表示、Excelで開けるCSV書き出し
- 遅延カメラ：5秒／10秒／20秒遅延、左右反転、全画面表示

HTML・CSS・JavaScriptのみで動作し、設定・作戦・記録はlocalStorageに保存します。カメラ映像は端末内の一時メモリで処理し、保存・送信しません。
